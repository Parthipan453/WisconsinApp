NetID Sign In

Signing in will give you access to library resources that are restricted (due to software licenses, copyright restrictions and other contractual agreements) to UW–Madison students, faculty, and staff.

More Information

Non UW-Madison Users

Access to WorldCat via FirstSearch is only available to Non UW–Madison Users when you are on campus. If you are not employed by or enrolled at the University you can also use the freely available WorldCat.org version.

Note that some functionality in the WorldCat.org version now requires users to create personal accounts on the platform.

NetID Information

If you need assistance with your NetID and password, please contact the DoIT Helpdesk. For security reasons, the Help Desk will only handle NetID and password issues over the phone.

NetID Account Utilities – Information on resetting passwords, activating accounts, and modifying accounts.

NetID Eligibility – Eligibility for a UW–Madison NetID and eligibility for remote access to library resources are not equivalent. Some NetID accounts may not allow access to library resources from off campus.
