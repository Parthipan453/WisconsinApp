How to Request Book Chapters

You may request a PDF version of a book chapter from any library, including UW–Madison Libraries, and receive an email notification when it is ready. Some restrictions may apply.

  1. First, check to see if the chapter is available online. Search the library catalog for the book title and check for online availability ("View Online").
  2. If you were not able to access the chapter online, then request a copy (UW–Madison faculty, staff, and students only).

If you were able to find a record of the print version of the book in the catalog, use the Request a Copy button to request a Partial Digitization . If you were not able to find the book in the catalog, submit an Interlibrary Loan Request using a blank form. We'll supply you with a PDF version of a UW–Madison print article or get a PDF copy from another library. Typical delivery is 1–3 days.

Questions? Ask a Librarian for assistance.
