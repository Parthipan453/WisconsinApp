Request Materials

UW–Madison faculty, staff and students have many ways to obtain library materials.

UW–Madison and UW System Materials

To find books, music, videos and more

Start with the Library Catalog to find materials in UW–Madison or UW System libraries. The Library Catalog also contains links to many online resources. For more information on how to search see Catalog Help .

To find articles

UW–Madison faculty, staff and students may use Article Search to find magazine, newspaper and scholarly articles, both on and off campus. Databases by Subject also lists hundreds of databases which give access to articles and other online publications.

Already have an item in mind or need more help? See the How to Request links on the right for details.

Questions? Ask a Librarian for assistance.

Materials from Other Libraries

When you're not able to find or access what you need from UW–Madison or UW System, try another library's collection. See the How to Request links on the right for more information.

Interlibrary Loan

You may search and place requests directly from WorldCat via FirstSearch .

See the Interlibrary Loan site for more information about the service.

Questions? Ask a Librarian for assistance.
