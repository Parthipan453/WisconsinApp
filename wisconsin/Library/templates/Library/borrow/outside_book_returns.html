Outside Book Returns at College, Memorial, and Steenbock

Returning books and media

Books and materials left you got from any campus location can be placed in the outside book returns at College, Memorial, or Steenbock Libraries. Book returns are available 24 hours a day, 7 days a week.

College Library Book Return

The book return is located on the south side of the building, to the right of the library entrance, facing Observatory Drive.

Memorial Library Book Return

The book return is located on the south side of the building, to the right of the library main entrance, facing the University Book Store.

Memorial Library also has an outside book return located on Lake Street, just north of State Street, on the loading dock. Although it is not a drive-up book drop, this location might be easier for people driving to campus who must park using available nearby parking.

Steenbock Library Book Return

The book return is located on the east side of the building, to the right of the library entrance, facing Babcock Drive.

Returning equipment

Return laptops and equipment to the original lending location during open hours. Please double-check that all cables, bags, and support materials are in the equipment bag before returning the item.
