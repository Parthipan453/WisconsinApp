How to Request Articles

Access articles directly, or if not available, request a copy and receive an email notification when it's ready. Some restrictions may apply.

1. First, check to see if the article is available online.

  • Type in one of the following – article title, journal title, PMID or DOI – to access the full text of the article.

2. If you were not able to access the article online, then request a copy (UW–Madison faculty, staff and students only).

  • We'll supply you with a PDF version of a UW–Madison print article, or get a PDF copy from another library.
  • To place your request, use the Request a Copy button in the library database record. If you aren't able to locate what you need in a library database, submit an Interlibrary Loan request using a blank form.
  • Typical delivery is 1–3 days.

Questions? Ask a Librarian for assistance.
