Open Return Libraries

The following campus libraries allow for most UW–Madison, UW System, and Interlibrary Loan items to be returned at their location:

  • AOSS Library
  • Art Library
  • College Library
  • Ebling Library
  • Gender and Women's Studies Librarian's Office
  • Historical Society
  • Law Library
  • Memorial Library
  • MERIT Library
  • Mills Music Library
  • School of Computer, Data, & Information Science Library
  • Social Work Library
  • Steenbock Library
  • Wisconsin Water Library

However, the following materials must be returned directly to the library from which they were borrowed:

  • Reserve items
  • Items with loan periods of 7 days or less
  • Journals and periodicals (bound or unbound)
  • Fragile materials (items prone to damage if dropped in a return bin)
  • Equipment (ex. laptops, cameras, recorders, headphones)
