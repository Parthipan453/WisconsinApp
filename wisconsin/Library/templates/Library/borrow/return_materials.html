Return Materials

Campus library users may return UW–Madison library books, including those borrowed via Interlibrary Loan, to a campus library other than the one from which they were borrowed.A list of Open Return Libraries may be found here.

However, the following materials must be returned directly to the library from which they were borrowed:

  • Reserve items
  • Items with loan periods of 7 days or less
  • Journals and periodicals (bound or unbound)
  • Fragile materials (items prone to damage if dropped in a return bin)
  • Equipment (ex. laptops, cameras, recorders, headphones)

Returning course reserves

Course reserve items have a 2-hour, 1-day, or 3-day loan period. Return course reserve materials to the same library that loaned them.

Returning equipment

Return laptop and other equipment to the original lending location during open hours. Please double-check that all cables, bags, and support materials are in the equipment bag before returning the item.

Mailing Items

Items may be returned via postal service to the address below. It is recommended that items be insured before sending via USPS, as patrons are responsible for materials until they reach the library. Please note that item replacement fees begin at $100.00.

Memorial Library, Room 166
728 State Street
Madison, WI 53706
