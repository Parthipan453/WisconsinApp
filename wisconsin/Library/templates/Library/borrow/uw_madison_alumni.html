UW–Madison Alumni

If you have questions or would like more information, contact Circulation Support.

All UW–Madison alumni have the following library privileges:

  • On-site library access
  • Access to UW–Madison licensed online resources while on campus
  • On-campus guest wireless access
  • Fee-based services (e.g. Wisconsin Tech Search)

All UW–Madison alumni may borrow materials by any of the following methods:

  • qualifying as a Courtesy Card Holder
  • purchasing an Annual Fee Card
  • becoming a donor to the Libraries' gift funds
  • contacting their local library to inquire about Interlibrary Loan options

Current UW–Madison Alumni Association paid members have some additional library privileges, including:

  • Access to several licensed databases. Login from the UW Alumni website to get access to these databases
  • Limited on-campus document delivery (up to 3 requests per week for print UW–Madison items)
  • Reference assistance

For more details, see WAA Member Online Library Services.
