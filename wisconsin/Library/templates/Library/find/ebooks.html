E-books

When accessed from an on-campus computer or through the campus wireless network, most e-books are available to all users. However, off-campus access requires a NetID login and is limited to students, staff, and faculty.

To find e-books, perform a search in the Library Catalog then check the box for Available Online and filter by the format Book. Each e-book's catalog record includes a link to the full text.

UW Libraries

UW Libraries subscribe to several dozen e-book databases. The content of each database is represented in the Library Catalog. When considering whether to use the Library Catalog or to search in a specific database, note that some e-book databases have a tight topical focus.

If your research is a match to the topical focus, it may be useful to search in that database instead of the Library Catalog for a full list of e-book databases. Click E-Book Collections.

For example: Bloomsbury Medieval Studies and Underground & Independent Comics, Comix, and Graphic Novels offer significantly different e-book choices.

Use E-books Online or Download

Each database functions differently, though most share some common traits.

  • Online: Most include an online e-book reader. Some e-book databases encourage users to make accounts in addition to their NetID login. Accounts enable keeping lists of items, making notes and creating tags.
  • Download: Some databases require special software (Adobe Digital Editions or OverDrive) to download books for offline reading.
  • Some databases require items to be checked out just like physical books. If another patron has borrowed the book, you'll usually see the expected return date.

E-books Not Owned by UW-Madison

Most libraries cannot share e-books with other libraries, therefore Interlibrary Loan cannot usually provide e-books. Consider these alternatives:

  • Interlibrary Loan may still provide a print copy if available.
  • Submit a Purchase Request for an e-book. While requests are not guaranteed, you'll be notified if the item is purchased.

Google Books

Google Books provides access to public-domain books and previews of millions of published books. It can be a useful supplement to the Library Catalog when searching for older or freely available digital books.
