2. Related Tools, Software and/or Code

{% endblock %} {% block content %}

Funding agencies will often ask you for information about the any specialized tools, software, or code that will be needed to access or manipulate your data. This is because they want to ensure that people have all the information they need to be able to open your files.

  • Specify if any software is necessary to work with the data files
    • Include information such as the name of the software, if applicable and whether they are open source or proprietary.
