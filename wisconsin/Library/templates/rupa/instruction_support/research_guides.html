Research Guides

UW–Madison Libraries Research Guides explore resources related to a specific subject, topic, course, or type of source. There are two primary types of Research Guides: Course Guides and Subject Guides.

Course Guides

Course Guides are guides created for a specific course and customized for the course topic and assignments. Course guides are created upon request and can be used as supplementary material to a library instruction session or as a standalone resource. To request a course guide, please fill out the Request Instruction form. The course guide will automatically appear in the Library Dashboard in your Canvas Course for immediate student access.

To request a course guide, please complete the Request Instruction Form . The completed guide will automatically appear in the Library Dashboard within your Canvas course.

Resources that can be included in a Course Guide:

  • Customized lists of books, databases, journals, and websites.
  • Research strategies for finding, evaluating, and using information.
  • Embedded tutorials and research support resources.

An example Course Guide from Communication Arts 262.

Subject Guides

Subject Guides are librarian-created guides that help users discover resources for a particular subject, topic, or type of resource.
