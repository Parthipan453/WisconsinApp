How to Build a Workflow

1. What is a Workflow?

A workflow defines the stages an application goes through from submission to decision. Each step is a checkpoint where staff review materials, fill forms, or make decisions.

2. Step Types

  • Form Section — Applicant fills out a form (linked to a Form Definition)
  • Review — Staff manually reviews materials and makes a verdict
  • Document Upload — Applicant uploads required documents (transcripts, IDs)
  • Payment — Application fee payment checkpoint
  • External Redirect — Send the applicant to an external site/portal
  • Submit — Final submission step

3. Adding Steps

Click "Add Step" to create a new step. Give it a code (unique ID), name, and select the step type. Link it to a form if the step requires applicant input.

4. Routing Conditions

Click the branch icon on any step to add conditions. Conditions control when a step is shown. For example:

  • Show "Transfer Transcript" step only when applicant_type = transfer
  • Show "International Documents" step only when applicant_type contains international
  • Skip "Essay" step when essay_waiver = true

5. Step Order

Steps execute in the order defined by Sort Order. Lower numbers run first. Use the edit button to change order.

6. Required vs Skippable

  • Required — Must be completed before advancing
  • Skippable — Applicant or reviewer can skip this step

7. Groups

Group related steps together with a group label. This helps organize the review process visually.
